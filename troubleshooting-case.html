Stage 3

Analyze the Crash Dump

The event log confirms that Windows captured crash evidence. Use the real dump in WinDbg on your workstation.

WinDbg investigation workflow
1. Download the crash dump below and note where it is saved.
2. Launch WinDbg.
3. Select File → Open dump file.
4. Browse to 051326-10687-01.dmp, select it, and click Open.
5. Allow the dump and symbols to finish loading.
6. In the initial analysis output, click the !analyze -v link to run the detailed Bugcheck Analysis.

Review the resulting analysis carefully. The Academy will ask you to extract evidence from the output; it will not identify the answer for you.
